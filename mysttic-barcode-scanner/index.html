What it does

An off-the-shelf scanner types one string and stops there. This one knows what it just read, and has four ways of getting it into a form.

It is a keyboard

Plug it in and it types, on any system that accepts a USB keyboard. No driver, nothing to install on the host. It reads a code held in front of it and does not type the same one twice.

A code comes apart into fields

Profiles recognise the kind of code and split it: GS1 into product number, expiry date, batch and serial, others by separator or by character position. The fields go out with TAB and ENTER between them, as slowly as the application needs.

Configured from the device

The scanner shows up as a small disk with the configurator on it. Build the profiles, see in Preview what a code turns into, try it in Test and save it to the device. Nothing is installed to do it.

Any web page, by field name

Decoy boxes or a shuffled order defeat a run of TABs. The browser extension puts each value in its field by name, and learns a new form in three steps: scan, name the parts, point at the boxes.

Any Windows application

An optional tray agent fills the controls of desktop applications by name. It learns a new application from one fill you do by hand while it records.

An answer from a server

An agent macro can send the scan to your HTTP endpoint and type back the answer, so one scan registers a code in one system and fills the returned number into another. Nothing is sent until you set it up.

Four ways into a form, from the simplest: A, the scanner types the fields with TAB, into any application with a fixed order of fields; B, a page whose code you own spreads them by name with a short script; C, any page in Chrome or Edge, single-page apps included, through the extension; D, the controls of Windows applications, kiosk mode included, through the agent.

How it looks

The four ways in 77 seconds, then one form before and after a scan.

What you need to build one

Two boards and a cable. The scanner module is the expensive part and the one that decides which symbologies you can read.

An RP2040 board

Ours is a YD-RP2040, a Pico clone with USB-C. Any RP2040 board with native USB runs the same firmware; one that reaches the computer through a USB-serial bridge cannot present itself as a keyboard.

A 1D/2D scanner module

Built against a Waveshare 14810; GM65 and GM805 behave the same way and take the same configuration codes. Its JST harness meets the board through four jumpers on a breadboard, UART crossing over.

A USB data cable

A charge-only cable is the most common reason nothing happens. Nothing else is fitted; an LED and a push button are optional, for status and factory reset.
