Why Mysttic Connect

The engine you know, cared for under a new name.

The engine you know

Mysttic Connect is built from the Mirth Connect 4.5.2 code. Your channels, scripts, code templates, extensions and database work as they do today, down to the last detail.

Proven identical

Compared with the official release file by file and run against it on 99 scenarios, with no difference beyond the product name. See it side by side.

Switch in an afternoon

Stop Mirth Connect, install, copy your configuration over, start. Nothing to export, convert or import, and the old installation stays as a way back.

Every platform

A Windows installer with the service and the Server Manager, packages for Linux and macOS servers, and the Administrator Launcher for Windows, macOS and Linux desktops.

Nothing calls home

No registration, no usage statistics, no vendor notifications. The server talks to your systems only; the launcher and the Server Manager ask this page for new versions, and you can turn that off.

Open source, numbered releases

Mozilla Public License 2.0. Every release has a number, a list of changes and signed updates, so you always know what you run.

Switching from Mirth Connect 4.5.2

An afternoon, not a project. Keep the old installation until you are sure.

1. Stop Mirth Connect

Stop the Mirth Connect service on the server it runs on. Nothing else changes yet.

2. Install and copy

Install Mysttic Connect next to it and copy your configuration and data over. Your channels, users, certificates and the database come with them.

3. Start it

Start Mysttic Connect: the Dashboard shows your channels as you left them. Remove the old service when you are ready.
